# The Minecraft Challenges

Fabric port for **Minecraft 26.2** (from Forge 1.9).

- Loader `0.19.5`, Fabric API `0.159.0+26.2`, Java 25, Mojmap
- Build: `./gradlew build` → `build/libs/challenge-2.0.0+26.2.jar`
- See `MIGRATION.md` and `PLAYTEST.md`

Local `fabric-26.2` branch; do not push until access is granted.
